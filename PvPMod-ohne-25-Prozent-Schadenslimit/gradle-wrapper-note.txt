This project uses lightweight Gradle bootstrap scripts (gradlew / gradlew.bat).
They download and run Gradle 9.2.1 on first use. The conventional gradle-wrapper.jar
is not included because this project was assembled in an environment without
network access. The Gradle distribution URL is also recorded in
 gradle/wrapper/gradle-wrapper.properties for reproducibility.

Build requirement: JDK 25 must be installed and selected as JAVA_HOME (or available
on PATH). The project compiles against Paper API 26.2.build.135-stable.
